=== MINECRAFT BEDROCK JSON UI - FULL REFERENCE ===

This document is a restructured compilation of the Minecraft Bedrock JSON UI engine documentation.
Use this resource to author, validate, and iterate on Bedrock JSON UI files.

================================================================================
1. ELEMENT TYPES
================================================================================

Name               Description                                                         Allowed Property Groups
------------------ ------------------------------------------------------------------  ------------------------------------
panel              A container, like <div> in HTML                                      Control, Layout, Data Binding
stack_panel        Like panel but stacks children by orientation                        Stack Panel, Collection, Control, Layout, Data Binding
collection_panel   Like stack_panel, no orientation property                            Collection, Control, Layout, Data Binding
grid               Grid of elements                                                     Grid, Collection, Control, Layout, Data Binding
label              Text element                                                         Text, Control, Layout, Data Binding
image              Sprite element. Draws a texture.                                     Sprite, Control, Layout, Data Binding
input_panel        A panel that accepts input                                           Input, Focus, Sound, Control, Layout, Data Binding
button             Button with 4 states: default, hover, pressed, locked                Button, Input, Focus, Sound, Control, Layout, Data Binding
toggle             Toggle with 2 states (checked/unchecked); each has hover & locked    Toggle, Input, Focus, Sound, Control, Layout, Data Binding
dropdown           A toggle for dropdown purposes                                       Dropdown, Toggle, Input, Focus, Sound, Control, Layout, Data Binding
slider             Range input element                                                  Slider, Input, Focus, Sound, Control, Layout, Data Binding
slider_box         The slider button/thumb                                              Slider Box, Input, Control, Layout, Data Binding
edit_box           Text field (default: single-line)                                    Text Edit, Button, Input, Focus, Control, Layout, Data Binding
scroll_view        Scrolling panel element                                              Scroll View, Input, Control, Layout, Data Binding
scrollbar_track    The scrollbar track                                                  Input, Control, Layout
scrollbar_box      The scrollbar thumb/draggable handle                                 Input, Control, Layout
factory            An element generator                                                 Control, Layout
screen             Screen element                                                       Screen, Control, Layout, Data Binding
custom             Special renderer (too complex for JSON UI)                           Custom Render, Control, Layout, Data Binding
selection_wheel                                                                         Selection Wheel, Input, Focus, Sound, Control, Layout, Data Binding

--- Legacy Element Types (no longer work) ---
tab, carousel_label, grid_item, scrollbar

--- 2b. Layout Properties ---
Property              Type              Default         Description
--------------------- ----------------- --------------- -----------------------------------------------
size                  Vector [w,h]      ["default","default"]  Size. Values: "default"(100%), N(px), "Npx", "N%", "N%c"(% of children total), "N%cm"(% of largest child), "N%sm"(% of sibling), "N%y"(% of element height), "N%x"(% of element width), "fill"(remaining space)
max_size              Vector [w,h]      ["default","default"]  Maximum size
min_size              Vector [w,h]      ["default","default"]  Minimum size
offset                Vector [x,y]      [0,0]           Position relative to parent (top-left based). Values: N(px), "Npx", "N%"(parent), "N%x"(element width), "N%y"(element height)
anchor_from           enum              center          Anchor point in the parent element
anchor_to             enum              center          Anchor point in the element itself
inherit_max_sibling_width  boolean      false           Use max sibling width
inherit_max_sibling_height boolean     false           Use max sibling height
use_anchored_offset   boolean
contained             boolean
draggable             enum                              Makes element draggable. Values: vertical, horizontal, both
follows_cursor        boolean           false           Follows the cursor

Anchor enum values: top_left, top_middle, top_right, left_middle, center, right_middle, bottom_left, bottom_middle, bottom_right

Anchor_from is the anchor point in the parent element.
Anchor_to is the anchor point in the element itself.
The anchor_to point attaches to the anchor_from point.

--- 2i. Variables Property ---
Property              Type        Description
--------------------- ----------- -----------------------------------------------
requires              string      Condition determining if variable values are applied. Accepts $variables, not #bindings.
variables             object/array Conditions that modify $variable values.

Usage:
Single condition: "variables": { "requires": "$condition", "$var": value }
Multiple: "variables": [ { "requires": "$condition", "$var": value }, ... ]

$var can be used in any property value by referencing $varname.
Default values: "$varname|default": value
